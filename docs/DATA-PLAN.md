### v11 (2026-11-19): cache-first reads + staged async refresh + chunked cloud
- **User complaint addressed**: entering the page must not re-pull everything; refresh must be asynchronous, progressive, and per-block. ### v107 (2026-11-20): entry performance — server read memoization + client stale-while-revalidate + SVG charts
- **User complaint addressed**: entering the console was slow on every visit despite all data being stored, and rendering felt blocking rather than asynchronous. Measured root causes: (1) `getDashboard` reloaded all ~307k `series_points` and recomputed every statistic (percentiles, drawdown archaeology, correlations, sims) from scratch on EVERY call — seconds of server CPU per entry for byte-identical output; the payload had also grown back to ~700 KB. ## Long-term data behavior
- **Refresh policy**: manual 刷新数据 button in the UI calling refreshData (user confirmed 2026-11-19 that automatic refresh is not required; keep it simple and reliable — no cron is installed, space.json managedCronJobs stays empty). Refresh = pure fetch + arithmetic; zero LLM/token use while the two API structures stay unchanged. Each refresh upserts series points and recomputes the indicator snapshot; refresh_log records time, source status, and per-source errors so a broken source shows honestly instead of going stale silently.
- **Growth**: series_points grows by ~15 symbols × 1 row/day plus ~8 yield series × 1 row/day; history windows are capped (prices 5y, yields 5y) and pruned on refresh.
- **Ordering**: dashboard reads the latest snapshot; indicator cards ordered macro → micro within each asset section; history stats always computed over the stated window, and the window is printed on every card.
- **Time semantics**: prices are each exchange's latest regular close (Yahoo regularMarketTime, shown in Asia/Shanghai); yields are Eastmoney's daily dated rows (SOLAR_DATE). Every card shows its data date so 休市/延迟 is visible, never implied live.

## Rejected approaches
- **Stooq CSV quotes**: tried `stooq.com/q/l/?s=^spx...` — returned a 'page does not exist' HTML shell from this network; Yahoo chart API covers the same symbols reliably.
- **Eastmoney push2 quote API for index prices**: returned 502 Bad Gateway from this VM; the datacenter-web subdomain works, so Eastmoney is used only for yields and all prices come from Yahoo (one stable price structure).
- **LLM-written daily commentary**: rejected — the user explicitly wants refreshes that cost basically no tokens once structures are stable; all interpretation on the page is rule-based labels computed from the numbers (position labels, trend states), and method explanations are fixed editorial copy written once at build time.
- **Live PE/valuation multiples**: Yahoo quote endpoint needs a crumb/cookie handshake that is brittle; '贵还是便宜' is answered honestly with price percentile, 52-week position, and drawdown-from-high over 5 years, labelled as price-position, not valuation.

Imagery: not needed — this is a data console; charts are drawn from the fetched series with the bundled chart library, and no photographic subjects exist in the brief.
